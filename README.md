# Model Observatory

Windows 本机模型用量账本：把 Codex、Cursor、pi、ZCode、DeepSeek Harness 等工具留下的调用记录，按具体模型汇总，查看请求数、已记录 Token、项目和会话。

**支持 Windows 10 / 11 x64。下载安装后即可使用，无需安装 Node.js、npm 或配置开发环境。**

## 1. 获取安装文件

前往 **[GitHub Releases 发行页](https://github.com/n1ght-ow/model-observatory/releases)**，选择最新发行版本，展开 **Assets（附件）**，下载其中一个 EXE：

| 文件 | 适合谁 | 使用方式 |
| --- | --- | --- |
| `Model-Observatory-<版本号>-Setup.exe` | 推荐日常使用 | 按向导安装，创建桌面和开始菜单快捷方式，支持开机启动 |
| `Model-Observatory-<版本号>-Portable.exe` | 想先试用或不想安装 | 放到固定文件夹，双击运行；不提供开机启动 |

**两种版本选一个即可。** 不要下载 `Source code (zip)` / `Source code (tar.gz)` 来安装应用，它们是源码。`.blockmap`、`.yml` 等文件也不需要手动下载。

如果发行页尚未提供安装文件，请向应用提供者获取上述 EXE；仅下载仓库源码无法直接安装。

### 已经拿到本地发行文件？

本仓库的发行产物放在 `dist/desktop/`。当前本地版本为 **0.2.8**，同一目录可能留有旧版本，请使用：

- **推荐安装包：** `Model-Observatory-0.2.8-Setup.exe`
- **免安装版：** `Model-Observatory-0.2.8-Portable.exe`

`0.2.6`、`0.2.7` 是旧版本，无需依次安装。`win-unpacked` 和其余构建辅助文件不需要复制给普通用户；换一台电脑安装时，只需传递选中的一个 EXE。

## 2. 安装并打开

### 安装版（推荐）

1. 双击下载的 `Model-Observatory-0.2.8-Setup.exe`（其他版本的安装步骤相同）。
2. 按安装向导选择安装位置并完成安装。
3. 从桌面或开始菜单打开 **Model Observatory**。

安装包尚未使用商业代码签名证书，Windows 可能提示“未知发布者”或“Windows 已保护你的电脑”。确认文件来自本项目发行页或可信的应用提供者后，如提示页提供该选项，可点击“更多信息 → 仍要运行”。

### 免安装版

1. 将 `Model-Observatory-0.2.8-Portable.exe` 放到打算长期保留的文件夹。
2. 双击 EXE 打开应用，以后仍从这个文件启动。

两种版本都自带运行所需组件，无需另外启动浏览器或网页服务。

## 3. 第一次使用

应用会自动读取**当前电脑**上支持的工具日志。首次打开可能需要等待历史补读，已有历史会先显示；后续每 15 秒在后台采集一次。

- **模型总览：** 查看各个具体模型的请求数和已记录 Token。
- **项目 / 会话：** 按本地记录中可靠的归属信息查看用量。
- **请求流水：** 筛选调用记录，并导出 CSV。
- **数字怎样算：** 查看来源状态、统计口径及已知边界。

默认只显示“今天”。如果看不到记录，可先切换到“全部”，再检查“数字怎样算”中的来源状态，以及是否暂停了后台采集。

应用依赖工具实际保留的本地记录；没有日志或日志缺少用量时，无法补出调用和 Token。未知值会保留为未知。换电脑安装不会自动带上原电脑的统计历史。

## 4. 关闭、退出与开机启动

- **点击窗口右上角 ×：** 收起到系统托盘，仍在后台采集。
- **重新打开窗口：** 双击 EXE / 快捷方式，或按 `Alt+A`（快捷键未被其他应用占用时）。
- **完全退出：** 在应用菜单或托盘菜单选择“退出”，也可在应用窗口按 `Ctrl+Q`。
- **开机启动：** 安装版中按 `Alt` 显示菜单，启用“开机启动”；之后开机进入托盘。免安装版不支持此功能。

## 5. 更新与卸载

**安装版更新：** 先从托盘菜单选择“退出”，再运行新版本的 `Setup.exe`，安装到原位置。关闭窗口只会收起到托盘，升级前请完全退出。

**免安装版更新：** 完全退出旧版后，用新版 `Portable.exe` 替换旧文件，再启动新版。

已采集历史保存在用户目录下的 `.model-observatory` 文件夹（默认 `%USERPROFILE%\.model-observatory`），与安装目录分开。更新时保留该文件夹即可继续使用原历史。

**卸载：** 安装版可在 Windows“设置 → 应用”中卸载；免安装版完全退出后删除 EXE 即可。统计历史不会随卸载自动删除。

## 遇到问题

启动失败时，可在启动页选择重试或查看诊断日志。默认桌面日志位于 `%APPDATA%\Model Observatory\logs\desktop.log`。

反馈问题请使用 [GitHub Issues](https://github.com/n1ght-ow/model-observatory/issues)，附上应用版本、Windows 版本、复现步骤和相关错误信息；分享日志前请检查并移除个人信息。
