## 下载文件校验

[SHA256SUMS-0.2.8.txt](SHA256SUMS-0.2.8.txt)记录 2026-10-23 当前本地安装包和免安装版的 SHA-256。[清单](manifest.json)同时记录文件名、字节数与校验值。这是文件一致性检查，不是代码签名，也不证明其他来源的同名文件可信。

在 PowerShell 中核对下载文件：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\Model-Observatory-0.2.8-Setup.exe
Get-FileHash -Algorithm SHA256 -LiteralPath .\Model-Observatory-0.2.8-Portable.exe
```

只需检查你下载的那一个 EXE。将结果与校验文件中对应文件名的值逐字比较，大小写不影响比较。

## 来源与处理边界

[manifest.json](manifest.json)逐文件记录本地原始相对路径、原始 SHA-256、公开副本 SHA-256、字节数和移除字段。绝对用户目录替换为 `<user-home>`，仓库目录替换为 `<workspace>`，去掉 ANSI 颜色控制码。安装版报告只公开功能断言、错误、导航、采集是否推进与构建比对；不公开真实模型用量汇总及用户数据目录。

`.gitattributes` 将本目录固定为 LF 换行，避免 Windows 检出时的换行转换改变公开文件校验值。

处理没有把失败改成成功，没有合并不同口径或重新计算性能数字。清单中的原始哈希用于标识本地来源，不能凭哈希独立恢复或验证没有公开的原始内容。

原始 fixture、会话数据库、完整采样、调试日志和新截图未随本次资料发布。JSON 中的 `logs/...`、`summary`、`failure` 等路径是原始运行的来源标识，不是本目录中的下载链接。因此这些材料可用于检查公开结果及其内部一致性，不能视为包含所有原始样本的独立重算证据包。重新测量请使用仓库脚本和隔离生成的 fixture。
